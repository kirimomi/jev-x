# jev-x

> **Jev (TypeSafe AI)** を活用した、X (旧Twitter) のリアルタイム・パーソナライズド・コンテンツフィルタリング拡張機能

---

## 🎯 概要

`jev-x` は、超高速・低コスト・高精度な決定モデル **Jev (TypeSafe AI)** を利用し、X（旧Twitter）のタイムライン上に流れる不快・不要なポストをリアルタイムに自動判定・マスキングするツールです。

見たくないカテゴリごとに **ON/OFFの個別切り替え** や感度調整が可能で、まずはPC向け **Chrome拡張機能** として構築し、その後 **スマートフォン（モバイル環境）** からも同様にフィルタリングされたタイムラインを閲覧できる環境を整えます。

---

## 🛡️ フィルタリング対象カテゴリ

各カテゴリは設定画面から個別に有効/無効を切り替え可能です。

| カテゴリ名 | ID | 概要・対象 |

| **インプレゾンビ** | `impression_zombie` | バズポストの丸パクリ・無断転載、コピペリプ、絵文字だけのリプ、脈絡のない外国語リプ |
| **ツリー・続き物誘導** | `thread_bait` | 「最後にとんでもないオチが…👇」「続きはツリー/プロフで」「知らなきゃ損する7選」などの露骨な引き伸ばし・滞在時間稼ぎ |

## 🏗️ システムアーキテクチャ

```
[ X (x.com) タイムライン ]
          │ (DOM監視: 本文 + 画像ALT + OGPカード[タイトル/説明/URL])
          ▼
[ クライアント前処理 (Chrome Extension) ]
  ├── ローカルキャッシュ (IndexedDB / chrome.storage)
  └── ルールベース即時判定 (正規表現・特定ユーザー)
          │ (未判定ポストをバッチ化)
          ▼
[ Jev API (@typesafe-ai/sdk) ]
  ├── 本文 + OGP情報を統合したStateを並列判定 (Score / Noul)
  └── 各カテゴリのスコア・確信度を返却 (sub-500ms)
          │
          ▼
[ UIレンダリング (アコーディオン式 たたむ/開く) ]
  ├── 該当ポストをコンパクトに「折りたたみ」
  ├── 理由バッジバーを表示 (例: "🛡️ AI Slop 92% | [ 表示する ▼ ]")
  └── ワンクリックで「開く/再度たたむ」を自由にトグル可能
```

## 🚀 インストール方法（一般ユーザー向け）

開発環境を構築せず、すぐに拡張機能を使いたい場合は以下の手順でインストールしてください。

1. **[Releases ページ](https://github.com/kirimomi/jev-x/releases)** から最新版のZIPファイル（例: `jev-x-v0.1.0.zip`）をダウンロードします。
2. ダウンロードしたZIPファイルを任意の場所に解凍（展開）します。
3. Google Chrome を開き、URLバーに `chrome://extensions/` と入力して拡張機能管理画面を開きます。
4. 画面右上の **「デベロッパー モード」** をONにします。
5. **「パッケージ化されていない拡張機能を読み込む」** をクリックし、手順2で解凍したフォルダを選択します。
6. インストール完了！

## 🛠️ 開発者向けガイド (Setup & Build)

### 開発用インストール手順
Node.js環境がある場合はソースコードからビルドして利用可能です。

- Node.js 20+
- npm 10+

### セットアップ・テスト
```bash
# 依存関係インストール
npm ci

# 型チェック
npm run typecheck

# 静的解析 (Lint)
npm run lint

# 単体テスト (Vitest)
npm test

# 拡張機能ビルド
npm run build:ext
```

### Chromeへのインストール手順 (開発用)
1. ビルド後、Chromeの拡張機能管理画面 (`chrome://extensions/`) を開きます。
2. **デベロッパー モード** をONにし、**「パッケージ化されていない拡張機能を読み込む」** からプロジェクトルート内の `dist/` ディレクトリを選択します。
