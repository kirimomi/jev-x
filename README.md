# jev-x

> **Jev (TypeSafe AI)** を活用した、X (旧Twitter) のリアルタイム・パーソナライズド・コンテンツフィルタリング拡張機能

---

## 🚀 インストール方法（とりあえず利用したい方向け）

> **⚠️ 注意: Jev APIキーが必要です**
> 本拡張機能を利用するには、判定エンジンである **Jev (TypeSafe AI) のAPIキー** が必要になります。拡張機能をインストール後、設定画面から取得したAPIキーを入力してください。

開発環境を構築せず、すぐに拡張機能を使いたい場合は以下の手順でインストールしてください。

1. **[Releases ページ](https://github.com/kirimomi/jev-x/releases)** から最新版のZIPファイル（例: `jev-x-v0.1.0.zip`）をダウンロードします。
2. ダウンロードしたZIPファイルを任意の場所に解凍（展開）します。
3. Google Chrome を開き、URLバーに `chrome://extensions/` と入力して拡張機能管理画面を開きます。
4. 画面右上の **「デベロッパー モード」** をONにします。
5. **「パッケージ化されていない拡張機能を読み込む」** をクリックし、手順2で解凍したフォルダを選択します。
6. インストール完了！

---

## 🎯 概要

`jev-x` は、超高速・低コスト・高精度な決定モデル **Jev (TypeSafe AI)** を利用し、X（旧Twitter）のタイムライン上に流れる不快・不要なポストをリアルタイムに自動判定・マスキングするツールです。

見たくないカテゴリごとに **ON/OFFの個別切り替え** や感度調整が可能で、まずはPC向け **Chrome拡張機能** として構築し、その後 **スマートフォン（モバイル環境）** からも同様にフィルタリングされたタイムラインを閲覧できる環境を整えます。

## 🛡️ フィルタリング対象カテゴリ

各カテゴリは設定画面から個別に有効/無効を切り替え可能です。

### 基本カテゴリ
| カテゴリ名 | ID | 概要・対象 |
| :--- | :--- | :--- |
| **アダルト / センシティブ** | `adult_nsfw` | 性的描写、風俗・裏垢・出会い系誘導、成人向け画像・テキスト |
| **AI Slop** | `ai_slop` | 粗製乱造された低品質AI画像/動画、ChatGPT生成の無機質なまとめ・解説・スパム |
| **インプレゾンビ** | `impression_zombie` | バズポストの丸パクリ・無断転載、コピペリプ、絵文字だけのリプ、脈絡のない外国語リプ |
| **ツリー・続き物誘導** | `thread_bait` | 「最後にとんでもないオチが…👇」「続きはツリー/プロフで」「知らなきゃ損する7選」などの露骨な引き伸ばし・滞在時間稼ぎ |

### 提案・拡張カテゴリ
| カテゴリ名 | ID | 概要・対象 |
| :--- | :--- | :--- |
| **炎上・対立煽り (Rage Bait)** | `rage_bait` | ジェンダー論争、世代間対立、特定属性・界隈への攻撃など、意図的に怒りや分断を煽る投稿 |
| **情報商材・怪しい副業** | `scam_hustle` | 「Brain発売」「月100万稼ぐプロンプト」「フォロー＆RTで限定配布」などの儲け話・勧誘 |
| **過度な愚痴・攻撃的怨嗟** | `toxic_venting` | 他者や社会への口汚い罵倒、呪詛、見ているだけで気が滅入る過剰なネガティブ感情の吐き出し |
| **ビジネス構文・自己啓発ポエム** | `preachy_guru` | 「優秀な人ほど〇〇しない」「これは残酷な真実ですが…」といった改行多用説教・マウント構文 |
| **アフィリエイト・ステマ投稿** | `affiliate_spam` | 「Amazonセールでこれだけは買え」「リプ欄にお得リンク」などの純粋な小遣い稼ぎリンク投稿 |
| **ネタバレ (Spoilers)** | `spoilers` | アニメ・漫画・映画・ゲームの最新話や結末に関する言及 |

## 🛠️ 開発者向け (ビルド方法)

Node.js (20+) および npm (10+) 環境が必要です。

```bash
# 依存関係のインストール
npm ci

# 拡張機能のビルド
npm run build:ext
```

ビルド完了後、`dist/` ディレクトリが生成されます。これを Chrome の拡張機能管理画面から「パッケージ化されていない拡張機能を読み込む」で読み込んでください。
